# 课程学习助手 (Lecture Watcher)

一个优雅的 Chrome 浏览器插件，帮你自动值守在线课程——检测弹窗、推进进度、处理意外页面，全程无需手动操作。

> 熄屏挂机、后台运行，课程自己跑完。🚀

---

## 功能一览

| 功能 | 说明 |
|------|------|
| 🛡️ **防挂机弹窗自动关闭** | 命中规则的特征文字弹窗，自动点击指定按钮关闭 |
| ⏱️ **倒计时自动推进** | 识别"还需 X 分钟"进度条，归零后自动点"下一节" |
| 🎬 **视频暂停检测** | 倒计时不变时自动点击播放，防止课程卡住 |
| 🔗 **外链打卡页处理** | 自动点击"立即前往"并导航回课程列表 |
| 🤖 **AI 截图辅助决策** | 未知页面连续 3 轮无法识别时，截图发给 AI Agent 判断下一步操作 |
| 📊 **实时运行计时** | 弹窗内显示已运行时长，随时开始/停止 |

## 安装

### 方式一：开发者模式安装

```bash
# 克隆本仓库
git clone https://github.com/YOUR_USERNAME/lecture-watcher.git
cd lecture-watcher/src
```

```bash
# Chrome 操作
1. 打开 chrome://extensions/
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录下的 src 文件夹
```

### 方式二：打包发布（Chrome Web Store）

```bash
# 打包命令
zip -r lecture-watcher.zip src/
```

## 快速开始

1. 点击工具栏插件图标打开设置弹窗
2. 在 **Agent 配置** 中填写 AI API 信息（可选，不填则无法处理复杂未知页面）
3. 在 **防挂机策略** 中调整/新增弹窗自动关闭规则
4. 打开任意在线课程页面，点击 **开启代课助手**
5. 锁屏 / 切出去，该干嘛干嘛 🎉

## 配置说明

### Agent 配置

| 字段 | 说明 | 示例 |
|------|------|------|
| Base URL | AI API 地址（兼容 Anthropic 格式） | `https://api.openai.com` |
| API Key | 密钥 | `sk-...` |
| Model | 模型名称 | `claude-sonnet-4-20250514` |
| 轮询间隔 | 检测频率，10s~5分钟可调 | `20`（默认 20 秒）|

> ⚠️ 如果不配置 Agent，插件仍可处理弹窗、倒计时、外链打卡等已知场景，仅在遇到未知任务/测验页面时无法自动推进。

### 防挂机策略

配置格式：`检测特征文字` + `点击按钮`，部分匹配即可。

| 检测特征文字 | 点击按钮 |
|-------------|---------|
| 系统禁止同时学习多个课程 | 继续学习 |
| 您已经打开过该课程 | 确定 |

## 工作原理

```
┌─────────────────────────────────────────────────────────┐
│                    content.js 轮询循环                    │
│                   （默认 20 秒间隔）                      │
└──────┬──────────┬──────────┬──────────┬─────────────────┘
       ▼          ▼          ▼          ▼
   1.弹窗检测  2.外链打卡  3.倒计时   4.未知状态
   (规则匹配)  (自动导航)  (视频控制)  (累计计数)
                                        │
                                   ≥3轮卡住
                                        ▼
                              background.js
                            截图 → AI Agent → 判断结果
                                    │
                              clickByText(action.text)
```

- **按需启动**：只有手动开启的标签页才运行，不影响其他页面
- **单标签页监控**：同一时间只监控一个标签页，切换目标时自动停止旧的
- **Tab 绑定**：监控的是标签页本身，URL 变化（如课程跳转）不影响监控

## 项目结构

```

├── src/
│   ├── manifest.json   # 插件清单 (Manifest V3)
│   ├── config.js      # 共享默认配置（防挂机规则）

└── .gitignore
```
